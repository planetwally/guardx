# GuardX

Static landing page for GitHub Pages. No build step.

## Publish

1. Create a GitHub repository.
2. Upload everything in this folder to the repository root (`index.html`, `styles.css`, `favicon.svg`, `.nojekyll`).
3. In the repository: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Branch `main`, folder `/ (root)`, then save.

The site will be at `https://<your-user>.github.io/<repo>/`.

If the repository is named `<your-user>.github.io`, the site is `https://<your-user>.github.io/`.
